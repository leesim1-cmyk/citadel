# citadel
collection of programs. will eventually turn into more with more inter-user interactions. currently in early-early-early alpha. the main idea behind this is to serve as a group of programs to help people focus, get stuff done, take small breaks, and (eventually) talk to other users. supposed to be a useful hub (NOT A DISTRACTION). don't use this to avoid work, use it to get it done. thanks

# setup
run setup.py first, to install all of the python modules required (in requirements.txt). after setup is successful, run menu.py. if there are issues, leave a comment. please remember, it is uber-early-alpha
